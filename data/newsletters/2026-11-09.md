## 3. Weekly Recipe
*Python drop-in client initialization using the SambaNova free tier:*

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.sambanova.ai/v1", api_key="your-sambanova-api-key"
)

    model="Meta-Llama-3.1-8B-Instruct",
```
