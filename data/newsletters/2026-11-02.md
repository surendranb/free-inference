## 2. Provider Spotlight: SambaNova Cloud
SambaNova Cloud provides high-throughput, low-latency inference on proprietary reconfigurable dataflow architecture (RDU) chips, offering free developer tier access to state-of-the-art open weights models.

* **Base URL**: `https://api.sambanova.ai/v1`
* **Authentication**: Bearer token via SambaNova account dashboard.
* **Free Tier Limits**: Generous rate limits designed for evaluation and prototyping, with strict usage policies against production traffic without a paid tier.
* **OpenAI Compatibility**: Drop-in replacement for standard OpenAI client libraries (`from openai import OpenAI`).
